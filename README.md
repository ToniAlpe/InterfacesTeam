# 📂 Tarea: Gestión de Interfaces y Herencia

Proyecto de Java realizado para la asignatura. El objetivo principal es practicar la implementación de interfaces y el uso de herencia entre clases (como la clase `PayPal`), siguiendo las instrucciones proporcionadas en clase.

## 📋 Objetivos de la tarea
* Implementación de la interfaz `MetodoPago`.
* Creación de clases que hereden o implementen comportamientos específicos.
* Validación de datos básicos por consola.

## 🛠️ Desarrollo actual
El proyecto sigue la lógica de programación estructurada y orientada a objetos básica:
* **Sin Arrays:** Se ha priorizado el uso de variables directas y lógica de control sencilla para ajustarse al temario dado en clase hasta ahora.
* **Interfaz de Consola:** La interacción se realiza íntegramente a través de la terminal de Java.

## 🚀 Cómo ejecutarlo
1. Abrir el proyecto en **IntelliJ IDEA**.
2. Localizar la clase `Main.java` en la carpeta `src`.
3. Hacer clic derecho y seleccionar **Run 'Main'**.
